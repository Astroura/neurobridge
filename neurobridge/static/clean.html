      03

      Processing method

      1. Check timestamps. Require approximately 256 Hz Muse EEG, finite increasing timestamps, and at least four seconds of samples. Split gaps over 20 ms. No reordering, resampling, or reconstruction.
      2. Flag suspicious raw data. Check each channel for missing values, samples near ±995 µV, 2-second peak-to-peak amplitude above your threshold, and 2-second flat windows (SD below 0.1 µV). These rules do not distinguish blinks from brain activity.
      3. Respect your exclusions. Manual intervals affect all channels. Extend artifact flags by 0.25 seconds on each side within continuous segments.
      4. Filter separate retained spans. SciPy designs a Butterworth 1–40 Hz band-pass in second-order sections (N=4, an eighth-order band-pass), applied forward and backward with sosfiltfilt (zero phase, squared magnitude response). Optional notch: 50/60 Hz, Q=30. This is offline processing; it uses future samples.
      5. Guard the edges. Discard clean spans shorter than three seconds and one second from each filtered span’s ends. This reduces edge effects without guaranteeing their removal. Excluded values remain blank/NaN.
      6. Measure retained data. Compute all-channel retention and descriptive theta/alpha/beta power using only intervals retained across all four sensors. Trial summaries use the existing listening markers when available.
      7. Save an audit trail. A new folder contains cleaned CSV and NumPy arrays, per-channel and common masks, rejection reasons, trial features, comparison PNG/PDF, processing settings, dependency versions, and a SHA-256 fingerprint of the original CSV. No ICA, interpolation, rereferencing, or comprehension classifier is used.

      All workspace exports include these results. The analysis ZIP contains this run only. For NumPy use np.load(path, allow_pickle=False); apply the “usable” mask before four-channel analysis.
